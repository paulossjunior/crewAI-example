# Dinner Pairing Crew 🍽️🍷📍

Toy example of [CrewAI](https://github.com/crewAIInc/crewAI) built with
[GitHub Spec Kit](https://github.com/github/spec-kit) (spec-driven development).

Three agents put together a dinner plan. Each one uses a recommender built on a **different
library**, exposed to it as a CrewAI tool. Each library fits a different kind of feedback data:

| Agent | Recommends | Library | Technique | Data | Code |
|---|---|---|---|---|---|
| Food Sommelier | dish | **LightFM** | hybrid (content + collaborative, WARP loss); new users are represented by their `--prefs` terms, so cold start works | user×dish likes + dish attributes + user preference terms | [food_lightfm.py](src/dinner_crew/recommenders/food_lightfm.py) |
| Wine Sommelier | wine | **implicit** | ALS on implicit feedback; the dish plays the "user", so wines ordered with similar dishes rank high | dish×wine order counts | [wine_implicit.py](src/dinner_crew/recommenders/wine_implicit.py) |
| Concierge | restaurant | **Surprise** | user-based KNNWithMeans (Pearson) on explicit 1–5 ratings | user×restaurant ratings | [restaurant_surprise.py](src/dinner_crew/recommenders/restaurant_surprise.py) |

A fourth agent, the **Host**, has no tool: it gathers the three answers into a warm, human summary
with ingredients, grape, prices and the dish + wine total, followed by the detailed plan.

Pipeline (sequential): dish → wine for that dish → restaurant serving that cuisine → host summary.

Two datasets with the same schema: `toy` (hand-written, default) and `large` (1,500 users,
~400 restaurants in 8 cities, ~37k ratings — generated by `scripts/generate_large_data.py`).

The recommenders are deterministic (fixed seeds, single thread) and never call the LLM. The LLM
only orchestrates the agents and writes the plan.

> **LightFM note:** upstream `lightfm` 1.17 does not build on Python 3.12, so the project depends
> on [`rectools-lightfm`](https://github.com/feldlime/rectools-lightfm), a maintained fork with the
> same `import lightfm` API.

📚 **Full documentation (Portuguese):** [docs/](docs/README.md) — tutorial, how-to guides,
reference and explanations of the architecture and the recommender systems.

## Install with Docker (app + Langfuse monitoring)

```bash
uv run python scripts/setup_langfuse_env.py   # once: secrets, Langfuse project and API keys
docker compose up -d --build
```

App on http://localhost:8501, Langfuse on http://localhost:3000 (login printed by the script).
Every crew run in "Com IA" mode becomes a trace: agents, tasks, tool calls and OpenAI calls with
tokens and cost. Details: [docs/guias/como-rodar-com-docker-e-langfuse.md](docs/guias/como-rodar-com-docker-e-langfuse.md).

## Setup (local, without Docker)

```bash
uv sync                      # Python 3.12 is picked from .python-version
cp .env.example .env         # then set OPENAI_API_KEY (and optionally OPENAI_MODEL)
```

## Usage

```bash
# Full crew (needs OPENAI_API_KEY)
uv run dinner-crew --prefs "cogumelos,cremoso,ervas" --user u1 --price media --city "São Paulo"

# Chat UI in the browser (offline mode by default; "Com IA" mode uses the crew)
uv run streamlit run src/dinner_crew/app.py

# Recommenders only, no LLM: prints the JSON each tool would give the agents
uv run dinner-crew --prefs "cogumelos,cremoso" --user u1 --dry-run

# Large dataset
uv run dinner-crew --prefs "peixe,cru" --city Recife --user u0100 --dataset large --dry-run

# Pin a dish, add restrictions
uv run dinner-crew --dish "Bife ancho com chimichurri" --dry-run
uv run dinner-crew --prefs "tomate,ervas" --restrictions vegano,sem_gluten --dry-run
```

Options: `--prefs`, `--restrictions` (`vegetariano`, `vegano`, `sem_gluten`, `sem_lactose`),
`--price` (`baixa|media|alta`), `--city`, `--user` (`u1`…`u8`; unknown → popularity fallback),
`--dish`, `--dataset` (`toy|large`), `--dry-run`. See [contracts/cli.md](specs/001-dinner-pairing-crew/contracts/cli.md).

## Tests

```bash
uv run pytest     # offline, no API key needed
```

## Toy data

[data/](data/) (toy): 19 dishes, 16 wines, 13 restaurants; 8 users with preference profiles, dish
likes and restaurant ratings; 57 dish×wine order counts. Every dish has ingredients and a price,
every wine a grape and bottle price, every restaurant an average ticket.

[data/large/](data/large/): generated — regenerate with `uv run python scripts/generate_large_data.py`.

## Site da documentação

The Portuguese docs in [docs/](docs/) (organized by Diátaxis) are also published as a website
built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) ([mkdocs.yml](mkdocs.yml)).

Preview locally (live reload at http://127.0.0.1:8000):

```bash
uv run --group docs mkdocs serve
```

Links from the docs to source files outside `docs/` are rewritten to GitHub URLs at build time by
[docs_hooks/github_links.py](docs_hooks/github_links.py).

On every push to `main` that touches the docs, the [docs workflow](.github/workflows/docs.yml)
builds the site with `--strict` and deploys it to GitHub Pages. Pages must be enabled once in the
repository settings (**Settings → Pages → Source: GitHub Actions**).
